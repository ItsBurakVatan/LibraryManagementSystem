# 🎮 Sıfırdan Oyun Geliştirme Rehberi

Merhaba! Bu proje, oyun geliştirme alanında hiçbir bilgisi olmayan kişiler için hazırlanmış kapsamlı bir rehberdir.

## 📁 Proje İçeriği

### 📚 Ana Rehberler:
- **`oyun-gelistirme-rehberi.md`** - Ana rehber ve genel bilgiler
- **`30_gunluk_plan.md`** - Detaylı 30 günlük öğrenme planı
- **`godot_kurulum.md`** - Godot Engine kurulum ve ilk adımlar
- **`kaynaklar_ve_linkler.md`** - Tüm öğrenme kaynakları ve linkler

### 💻 Örnek Kodlar:
- **`ilk_oyunum.py`** - İlk Python oyununuz (Sayı Tahmin Oyunu)
- **`basit_pygame_ornegi.py`** - Pygame ile basit hareket oyunu

## 🚀 Nasıl Başlayacaksınız?

### 1. İlk Adım: Ana Rehberi Okuyun
```bash
# Ana rehberi açın
cat oyun-gelistirme-rehberi.md
```

### 2. 30 Günlük Planı İnceleyin
```bash
# Detaylı planı görün
cat 30_gunluk_plan.md
```

### 3. İlk Oyununuzu Çalıştırın
```bash
# Python oyununu test edin
python3 ilk_oyunum.py
```

### 4. Godot'u Kurun
```bash
# Godot kurulum rehberini okuyun
cat godot_kurulum.md
```

### 5. Kaynakları Keşfedin
```bash
# Tüm öğrenme kaynaklarını görün
cat kaynaklar_ve_linkler.md
```

## 🎯 Öğrenme Yolculuğunuz

1. **Hafta 1**: Python temelleri ve ilk oyun
2. **Hafta 2**: Godot Engine'e giriş
3. **Hafta 3**: İlk gerçek oyun projesi (Pong)
4. **Hafta 4**: Geliştirmeler ve gelecek planları
